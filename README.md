## 🌐 הפעלה דרך GitHub Pages

1. צרו Repository חדש בשם KingBalance ב־GitHub.
2. העלו את **תוכן התיקייה** (לא את קובץ ה־ZIP עצמו).
3. ב־Settings → Pages בחרו Deploy from a branch, ואז main ו־/(root).
4. לאחר הפריסה, פתחו את הקישור ש־GitHub מציג. אין צורך ב־npm או בהתקנה.

הממשק טוען את קובצי ה־Markdown מהמאגר דרך HTTP; לפתיחה מקומית יש להפעיל שרת סטטי קטן, למשל הפקודה: \`python3 -m http.server 8000\`, ולבקר בכתובת http://localhost:8000.
