## 🌐 הפעלה דרך GitHub Pages

1. צרו Repository חדש בשם KingBalance ב־GitHub.
2. העלו את **תוכן התיקייה** (לא את קובץ ה־ZIP עצמו).
3. ב־Settings → Pages בחרו Deploy from a branch, ואז main ו־/(root).
4. לאחר הפריסה, פתחו את הקישור ש־GitHub מציג. אין צורך ב־npm או בהתקנה.

הממשק טוען את קובצי ה־Markdown מהמאגר דרך HTTP; לפתיחה מקומית יש להפעיל שרת סטטי קטן, למשל הפקודה: \`python3 -m http.server 8000\`, ולבקר בכתובת http://localhost:8000.

- **KB-031—KB-040 הושלמו.** נשמרו 18 ליקוטי היסוד המקוריים, ובמקביל נוספה חפיסה מורחבת בת 44 זוגות.
- כל קלף מכיל ״סור מרע״, ״עשה טוב״, ארבע שכבות פרד״ס, תרגול, משפט קצר לשיתוף והפניה נושאית לפרק ולעמוד בחוברת המקור. **פירוש הפרד״ס אינו מיוחס למחבר המקור**.
- את הקלף היומי בוחר חישוב קבוע על בסיס תאריך אזור הזמן *Asia/Jerusalem*, כך שכל המבקרים מקבלים אותו קלף באותו יום בישראל. אפשר גם לשלוף קלף אחר באקראי.

- להפעלה מחדש: `node scripts/build_card_docs.mjs` ליצירת מדריכי Markdown, ואחרי `pip install -r requirements-print.txt` הפקודה `python3 scripts/build_cards.py` לייצור הקלפים (נדרש גם גופן DejaVu Sans).
