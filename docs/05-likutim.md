## 🛠️ איך להשתמש בכל ליקוט

1. קרא את שני חלקי המשפט.
2. תאר מצב אמיתי שבו הופיע הצד של ״סור מרע״.
3. בחר פעולה קטנה מתוך הצד של ״עשה טוב״.
4. בסוף היום שאל: מה עשיתי בפועל? מה למדתי?

## 🎴 מבנה קלף עתידי

- **חזית:** מספר, סמל, כותרת, משפט ״סור מרע״.
- **גב:** ״עשה טוב״, ביאור, נימוק, תרגיל והפניה למקור.
- **שכבת עומק:** פשט, רמז, דרש, סוד — רק כשיש הקשר תורני מתאים והבחנה בין מקור לחידוש.
